# Reach out

For help with drugMR, contact Guillermo Comesaña Cimadevila or Professor Valentina Escott Price at Cardiff University.

| Contact | Best for | Details |
| --- | --- | --- |
| Guillermo Comesaña Cimadevila | Installation, configuration, pipeline runs, QTL manifests, errors, dashboard use, and code contributions | [ComesanaCimadevilaG@cardiff.ac.uk](mailto:ComesanaCimadevilaG@cardiff.ac.uk) and [Cardiff University profile](https://profiles.cardiff.ac.uk/research-staff/comesanacimadevilag) |
| Professor Valentina Escott Price | Scientific questions, interpretation, collaboration, and study design | [EscottPriceV@cardiff.ac.uk](mailto:EscottPriceV@cardiff.ac.uk) and [Cardiff University profile](https://profiles.cardiff.ac.uk/staff/escottpricev) |

When asking about a failed run, include the drugMR Git revision, params file, QTL manifest row, run ID, Nextflow command, container profile, and the final error block from the `.out` or `.nextflow.log` file. Do not send restricted individual level data, passwords, private keys, access tokens, or complete controlled datasets by email or in a public GitHub issue.

For a reproducible software bug that contains no sensitive information, open an issue in the [drugMR GitHub repository](https://github.com/guillermocomesanacimadevila/drugMR/issues). Include a minimal example and state whether the run was local or on HPC.
