# Results

Every successful analysis is stored under `runs/<run_id>/`. The run ID identifies one outcome trait, one pQTL dataset, the run date, and the Git revision. The directory contains the locked parameters, provenance, Nextflow execution records, final tables, sensitivity outputs, and portable locus data.

## Run contents

| Path | Contents and use |
| --- | --- |
| `manifest.json` | Run identity, phenotype, pQTL dataset, Git revision, container image, host, creation time, and the name of the locked params file. |
| `params.lock.yaml` | The effective parameters and gates used by this exact run. Pass this file to `dm.results()` to reopen the exact local run. |
| `pipeline_info/execution_report_<timestamp>.html` | Nextflow task summary with status, duration, CPU use, memory use, reads, writes, and cached task information. |
| `pipeline_info/execution_timeline_<timestamp>.html` | Timeline of process scheduling and execution. |
| `pipeline_info/execution_trace_<timestamp>.txt` | Machine readable task trace for performance analysis and audit. |
| `pipeline_info/pipeline_dag_<timestamp>.svg` | DAG generated by Nextflow for the executed workflow. Graphviz is required to render it as SVG. |
| `results/cis_mr/mr.tsv` | One MR summary row per tested protein, including the primary method, effect estimate, FDR, heterogeneity, power, and sensitivity estimators. |
| `results/cis_mr/instruments/mr_instruments.tsv` | Instrument level SNP data used by MR, colocalisation, PWCoCo, and PheWAS. |
| `results/coloc/<pqtl_dataset>_<pheno_id>_all_coloc.tsv` | Pairwise pQTL and outcome GWAS colocalisation results for every tested protein. |
| `results/coloc/coloc_sensitivity.tsv` | Colocalisation sensitivity results across the configured prior values. |
| `results/pwcoco/summary/pwcoco.tsv` | Conditional pQTL and outcome GWAS colocalisation summary. |
| `results/pwcoco/summary/pwcoco_eqtl_pqtl.tsv` | QTL and pQTL conditional colocalisation results for supported multi omic targets. |
| `results/pwcoco/summary/pwcoco_eqtl_gwas.tsv` | QTL and outcome GWAS conditional colocalisation results. |
| `results/pwcoco/summary/pwcoco_shared_snps.tsv` | Shared conditional SNP evidence when available. |
| `results/target_stats/top_cis_hits.tsv` | Targets supported by the MR and colocalisation gates. This table drives locus export and downstream triangulation. |
| `results/locus_data/index.tsv` | Index of portable dashboard loci. |
| `results/locus_data/<target>/gwas.parquet` | Outcome GWAS associations for the target locus. |
| `results/locus_data/<target>/pqtl.parquet` | pQTL associations for the same locus. |
| `results/locus_data/<target>/ld.parquet` | LD to the lead SNP when the configured reference contains the required variants. This file is optional. |
| `results/locus_data/<target>/metadata.json` | Target, locus, lead SNP, source, and LD provenance used by the dashboard. |
| `results/smr/bulk/<qtl_dataset>/promising_targets.tsv` | SMR and HEIDI results retained from one bulk QTL dataset or grouped bulk collection. |
| `results/smr/sc/<qtl_dataset>/promising_targets.tsv` | SMR and HEIDI results retained from the configured single cell QTL dataset. |
| `results/smr/final_multi_omics_targets.tsv` | Combined bulk and single cell SMR results used by QTL PWCoCo, HyPrColoc, and the dashboard. |
| `results/hyprcoloc/by_eqtl_source/<qtl_dataset>/hyprcoloc.tsv` | HyPrColoc results for one QTL source. |
| `results/hyprcoloc/by_eqtl_source/*.pdf` | Per target HyPrColoc sensitivity figures when generated. |
| `results/hyprcoloc/hyprcoloc.tsv` | Combined HyPrColoc result across the enabled QTL sources. |
| `results/phewas/finngen/phewas_coverage.tsv` | FinnGen instrument coverage for every screened target. Coverage is reported even when no significant PheWAS hit is found. |
| `results/phewas/finngen/phewas.tsv` | FinnGen safety and repurposing associations when hits are present. |
| `results/phewas/ukbb/phewas.tsv` | UK Biobank PheWAS associations when the stage is enabled and results are present. |

Files from optional stages may be absent when the stage is disabled, no target passes the preceding gate, no phenotype has sufficient instrument coverage, or the LD reference lacks the locus variants. Absence of an optional association table is therefore different from a failed Nextflow process. Use the execution report and trace to distinguish the two cases.

The sections below describe the principal result columns. Column names are retained exactly as produced because the dashboard reads the same names.

## Cis MR results

File: `results/cis_mr/mr.tsv`

One row per protein. `primary_*` mirrors whichever method (`Wald` or `IVW`) was actually used for that protein, based on `n_instruments`.

| Column | Meaning |
| --- | --- |
| `protein` | Protein identifier (`GENE_UNIPROT` or `GENE_ENSEMBL`, dataset-dependent) |
| `pqtl_dataset`, `outcome_trait` | Which pQTL panel and outcome this row is from |
| `n_instruments` | Number of independent cis-instruments for this protein |
| `methods_run` | Which MR methods were run given `n_instruments` |
| `primary_method`, `primary_beta`, `primary_se`, `primary_pval`, `primary_FDR_q` | The method actually used to gate this protein: Wald ratio if `n_instruments == 1`, IVW otherwise |
| `MDE_OR` | Minimum detectable effect (odds ratio), for power context |
| `IVW_beta/se/pval/FDR_q` | Inverse-variance-weighted estimate (`n_instruments > 1`) |
| `Egger_beta/se/pval/FDR_q`, `egger_intercept`, `egger_intercept_pval` | MR-Egger estimate and pleiotropy intercept test |
| `WME_beta/se/pval/FDR_q` | Weighted median estimator |
| `Wald_beta/se/pval/FDR_q` | Wald ratio estimate (`n_instruments == 1`) |
| `Q`, `Q_df`, `Q_pval` | Cochran's Q heterogeneity statistic, degrees of freedom, p-value |

**Gate to next stage:** `Wald_FDR_q < 0.05` (1 instrument) OR (`IVW_FDR_q < 0.05` AND `Q_pval > 0.05`).

## Pairwise colocalisation results

File: `results/coloc/<pqtl_dataset>_<pheno_id>_all_coloc.tsv`

One row per protein, from `bin/coloc.R`.

| Column | Meaning |
| --- | --- |
| `protein_id`, `outcome_trait` | Protein and outcome this coloc run covers |
| `top_snp`, `nsnps` | Lead SNP in the tested region and number of SNPs used |
| `PP.H0.abf` … `PP.H4.abf` | Posterior probabilities for coloc's five hypotheses (H4 = shared causal variant) |
| `coloc_pass` | Pre-computed boolean: `PP.H4.abf > pp4_threshold` |
| `pp4_threshold` | The PP.H4 cutoff recorded in the result. Read this value from the result because it is configurable. |
| `n_pqtl_snps`, `n_gwas_snps`, `n_gwas`, `s_gwas` | SNP counts and outcome GWAS sample size / case fraction used in the coloc run |
| `n_cases`, `n_controls` | Outcome GWAS case/control counts |

**Gate to next stage:** `coloc_pass == True` (i.e. `PP.H4.abf > 0.7`).

## SMR and HEIDI results

File: `results/smr/final_multi_omics_targets.tsv`

This is the canonical combined SMR output read by the dashboard. It contains one row per target and cell type or tissue, with bulk and single cell rows appended together. Columns up to `Lead_SNP_BP` come from the `smr` binary. Everything from `q_SMR` onward is added by `bin/sort_smr.py`.

| Column | Meaning |
| --- | --- |
| `Gene`, `probeID`, `gene_id` | Gene symbol / probe / Ensembl-style ID for the eQTL probe |
| `qtl_name` | Source eQTL sub-dataset label (e.g. `eQTL_GTEx_Brain_Cortex_v10`) |
| `ProbeChr`, `Probe_bp`, `chr`, `start`, `end`, `strand` | Probe genomic coordinates |
| `topSNP`, `topSNP_chr`, `topSNP_bp` | SMR's top associated SNP and its position |
| `A1`, `A2`, `Freq` | Alleles and effect-allele frequency, aligned so `A1` is always the AD risk-increasing allele (see `align_to_risk_allele` in `bin/sort_smr.py`) |
| `b_GWAS`, `se_GWAS`, `p_GWAS` | Outcome GWAS effect at the top SNP |
| `b_eQTL`, `se_eQTL`, `p_eQTL` | QTL effect at the top SNP. For single cell targets, this is checked against the original registered cell type file. |
| `b_SMR`, `se_SMR`, `p_SMR`, `p_SMR_multi` | SMR effect estimate (`b_GWAS / b_eQTL`) and test p-values |
| `p_HEIDI`, `nsnp_HEIDI` | HEIDI heterogeneity test p-value and number of SNPs used |
| `GWAS_LOCUS`, `Lead_SNP`, `Lead_SNP_BP` | Outcome GWAS locus this probe falls in |
| `q_SMR` | FDR-corrected `p_SMR`, computed per-file across every probe (not just promising targets) by `fdr_correct_smr_file` |
| `protein` | Target identifier, mapped back from `Gene` |
| `cell_type` | Cell type (single-cell) or tissue/sub-dataset label (bulk) |
| `data_type` | `bulk` or `single_cell` |
| `phenotype`, `eqtl_dataset`, `pqtl_dataset` | Run identity columns |

**Gate to "Final Targets":** `q_SMR < 0.05` AND `p_HEIDI > 0.01`.

## PheWAS results

Files: `results/phewas/finngen/phewas.tsv` and `results/phewas/ukbb/phewas.tsv`

Each row represents one protein and PheWAS outcome phenotype. FinnGen and UK Biobank results use the same main result shape.

| Column | Meaning |
| --- | --- |
| `protein`, `pqtl_dataset`, `method` | Target and which MR method produced `beta_mr` |
| `n_instruments_original/available`, `missing_instruments`, `instrument_completeness` | How many of the protein's cis-instruments were found in this PheWAS outcome's GWAS |
| `rsid`, `snp`, `A1`, `A2` | Instrument SNP and alleles, aligned to the AD risk allele |
| `ad_effect_allele_original`, `ad_other_allele_original`, `beta_ad_original`, `beta_ad`, `ad_A1_flipped` | Original vs. risk-allele-aligned AD effect |
| `exposure_effect_allele`, `exposure_other_allele`, `beta_exposure(_original)`, `se_exposure`, `p_exposure`, `exposure_A1_flipped` | pQTL (exposure) effect, original vs. aligned |
| `finngen_ref`, `finngen_alt`, `phewas_A1_flipped` | PheWAS outcome's own allele coding and whether it was flipped to match |
| `beta_mr`, `se_mr`, `p_mr` | MR estimate of the protein's effect on this PheWAS outcome |
| `beta_phewas`, `se_phewas`, `p_phewas` | Raw PheWAS outcome GWAS association at the instrument SNP |
| `PHENOCODE`, `PHENOSTRING`, `CATEGORY` | PheWAS outcome phenotype identity |
| `p_bonferroni`, `bonferroni_significant` | Bonferroni-corrected p-value and significance flag |

**Safety gate:** a target fails only if it has a `bonferroni_significant` association with `beta_mr >= 0`, meaning that the same allele increasing outcome risk also increases the PheWAS outcome. A target passes when there is no significant hit, when the significant effect is protective with `beta_mr < 0`, or when no coverage is available.
