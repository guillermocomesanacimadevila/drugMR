# Results

Every successful analysis is stored under `runs/<run_id>/`. The run ID identifies one outcome trait, one pQTL dataset, the run date, and the Git revision. The directory contains the locked parameters, provenance, Nextflow execution records, final tables, sensitivity outputs, and portable locus data.

## Run contents

| Path | Contents and use |
| --- | --- |
| `manifest.json` | Run identity, phenotype, pQTL dataset, Git revision, container image, host, creation time, and the name of the locked params file. |
| `params.lock.yaml` | The effective parameters and gates used by this exact run. Pass this file to `dm.results()` to reopen the exact local run. |
| `pipeline_info/execution_report_<timestamp>.html` | Nextflow task summary with status, duration, CPU use, memory use, reads, writes, and cached task information. |
| `pipeline_info/execution_timeline_<timestamp>.html` | Timeline of process scheduling and execution. |
| `pipeline_info/execution_trace_<timestamp>.txt` | Machine readable task trace for performance analysis and audit. |
| `pipeline_info/pipeline_dag_<timestamp>.svg` | DAG generated by Nextflow for the executed workflow. Graphviz is required to render it as SVG. |
| `results/cis_mr/mr.tsv` | One MR summary row per tested protein, including the primary method, effect estimate, FDR, heterogeneity, and sensitivity estimators. |
| `results/cis_mr/instruments/mr_instruments.tsv` | Instrument level SNP data used by MR, colocalisation, PWCoCo, and PheWAS. |
| `results/coloc/<pqtl_dataset>_<pheno_id>_all_coloc.tsv` | Pairwise pQTL and outcome GWAS colocalisation results for every tested protein. |
| `results/coloc/coloc_sensitivity.tsv` | Colocalisation sensitivity results across the configured prior values. |
| `results/pwcoco/summary/pwcoco.tsv` | Conditional pQTL and outcome GWAS colocalisation summary. |
| `results/pwcoco/summary/pwcoco_eqtl_pqtl.tsv` | QTL and pQTL conditional colocalisation results for supported multi omic targets. |
| `results/pwcoco/summary/pwcoco_eqtl_gwas.tsv` | QTL and outcome GWAS conditional colocalisation results. |
| `results/pwcoco/summary/pwcoco_shared_snps.tsv` | Shared conditional SNP evidence when available. |
| `results/target_stats/top_cis_hits.tsv` | Targets supported by the MR and colocalisation gates. This table drives locus export and downstream triangulation. |
| `results/locus_data/index.tsv` | Index of portable dashboard loci. |
| `results/locus_data/<target>/gwas.parquet` | Outcome GWAS associations for the target locus. |
| `results/locus_data/<target>/pqtl.parquet` | pQTL associations for the same locus. |
| `results/locus_data/<target>/ld.parquet` | LD to the lead SNP when the configured reference contains the required variants. This file is optional. |
| `results/locus_data/<target>/metadata.json` | Target, locus, lead SNP, source, and LD provenance used by the dashboard. |
| `results/smr/bulk/<qtl_dataset>/promising_targets.tsv` | SMR and HEIDI results retained from one bulk QTL dataset or grouped bulk collection. |
| `results/smr/sc/<qtl_dataset>/promising_targets.tsv` | SMR and HEIDI results retained from the configured single cell QTL dataset. |
| `results/smr/final_multi_omics_targets.tsv` | Combined bulk and single cell SMR results used by QTL PWCoCo, HyPrColoc, and the dashboard. |
| `results/hyprcoloc/by_eqtl_source/<qtl_dataset>/hyprcoloc.tsv` | HyPrColoc results for one QTL source. |
| `results/hyprcoloc/by_eqtl_source/*.pdf` | Per target HyPrColoc sensitivity figures when generated. |
| `results/hyprcoloc/hyprcoloc.tsv` | Combined HyPrColoc result across the enabled QTL sources. |
| `results/phewas/finngen/phewas_coverage.tsv` | FinnGen instrument coverage for every screened target. Coverage is reported even when no significant PheWAS hit is found. |
| `results/phewas/finngen/phewas.tsv` | FinnGen associations classified as potential adverse effects or repurposing opportunities, when present. |
| `results/phewas/ukbb/phewas.tsv` | UK Biobank PheWAS associations when the stage is enabled and results are present. |

Files from optional stages may be absent when the stage is disabled, no target passes the preceding gate, no phenotype has sufficient instrument coverage, or the LD reference lacks the locus variants. Absence of an optional association table is therefore different from a failed Nextflow process. Use the execution report and trace to distinguish the two cases.

Column names in every file are retained exactly as produced, because the dashboard reads the same names. The gate thresholds that decide which targets carry forward at each stage are set in the `gates` block described in [Configure a run](configuration.md), and the value actually used for a given run is always recorded alongside its results.

## Key table columns

Columns of the four tables most often read directly. Allele columns follow the convention in [Methods](methods.md#effect-direction).

### `results/cis_mr/mr.tsv`

One row per protein tested.

| Column | Meaning |
| --- | --- |
| `protein`, `pqtl_dataset`, `outcome_trait` | Run identifiers. |
| `n_instruments` | Instruments left after clumping and F statistic filtering. |
| `methods_run` | MR methods applied, which depend on `n_instruments`. |
| `primary_method` | Wald ratio for 1 instrument, IVW for 2 or more. |
| `primary_beta`, `primary_se`, `primary_pval` | Primary estimate: change in outcome log odds (or outcome units) per unit increase in protein level. |
| `primary_FDR_q` | FDR q value of `primary_pval` across all proteins in the panel. This is the value the cis-MR gate uses. |
| `IVW_*`, `Egger_*`, `WME_*`, `Wald_*` | Estimate, SE, P and FDR q for each method. FDR is computed within each method, so these q values are not used for gating. |
| `egger_intercept`, `egger_intercept_pval` | MR Egger intercept and its P value (3 or more instruments). |
| `Q`, `Q_df`, `Q_pval` | Cochran's Q heterogeneity test for IVW (2 or more instruments). |

### `results/target_stats/top_cis_hits.tsv`

One row per target passing cis-MR and colocalisation, describing its lead pQTL SNP.

| Column | Meaning |
| --- | --- |
| `protein` | Target. |
| `SNP` | Lowest P pQTL SNP in the cis region. |
| `A1`, `A2` | Outcome GWAS risk allele and other allele. |
| `FRQ` | Frequency of `A1` in the outcome GWAS. |
| `GWAS_BETA`, `GWAS_P` | Outcome GWAS effect of `A1` (always positive) and its P value. |
| `pQTL_BETA`, `pQTL_P` | pQTL effect of `A1` and its P value. A positive value points to inhibition, a negative value to activation. |
| `outcome_trait` | Outcome phenotype ID. |

### `results/smr/final_multi_omics_targets.tsv`

One row per target, QTL dataset and tissue or cell type that passes the SMR and HEIDI gate.

| Column | Meaning |
| --- | --- |
| `protein`, `Gene`, `probe_id`, `probe_chr`, `Probe_bp` | Target, QTL gene symbol, QTL probe ID and probe position. |
| `top_snp`, `top_snp_chr`, `top_snp_bp` | Top cis QTL SNP used by SMR. |
| `A1`, `A2`, `Freq` | Alleles and `A1` frequency for the top SNP. |
| `b_GWAS`, `se_GWAS`, `p_GWAS` | Outcome GWAS effect of the top SNP. |
| `b_qtl`, `se_qtl`, `p_qtl` | QTL effect of the top SNP. |
| `b_SMR`, `se_SMR`, `p_SMR` | SMR estimate of the effect of the QTL trait on the outcome. |
| `q_SMR` | FDR q value of `p_SMR` within the QTL dataset. |
| `p_HEIDI`, `nsnp_HEIDI` | HEIDI test P and the number of SNPs it used. Low P suggests linkage rather than one shared variant. |
| `qtl_dataset`, `qtl_name`, `qtl_type` | QTL source, tissue or file label, and QTL type (eQTL, sQTL and so on). |
| `data_type`, `cell_type` | `bulk` or `sc`, and the cell type for single cell rows. |
| `pqtl_dataset`, `phenotype` | Run identifiers. |

### `results/hyprcoloc/hyprcoloc.tsv`

One row per HyPrColoc cluster for each target and QTL source.

| Column | Meaning |
| --- | --- |
| `protein`, `pqtl_dataset`, `outcome_trait`, `qtl_dataset`, `qtl_type`, `data_type`, `cell_type` | Target and data sources. |
| `iteration` | HyPrColoc cluster number. |
| `traits` | Traits in the cluster. A target passes only when the cluster holds the pQTL, the QTL and the outcome GWAS together. |
| `posterior_prob` | Posterior probability that the traits in the cluster share one causal variant. |
| `regional_prob` | Regional association probability. |
| `candidate_snp`, `posterior_explained_by_snp` | Most likely shared causal SNP and the share of `posterior_prob` it explains. |
| `dropped_trait` | Trait removed by HyPrColoc's branch and bound step, when any. |
| `n_snps` | SNPs shared by all traits in the region. |
| `a1`, `a2`, `gwas_beta`, `gwas_p`, `pqtl_beta`, `pqtl_p`, `qtl_beta`, `qtl_p` | Candidate SNP effects aligned to the outcome GWAS risk allele `a1`. |
